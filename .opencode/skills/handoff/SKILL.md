# handoff

Only when they say they're stopping — "wrap up", "that's it for today", "save where we are".

## Write HANDOFF.md

Overwrite it each time; it's a note about *now*, not a diary. Four short parts, in plain English:

1. **Where things stand** — what works now, and anything half-finished (say exactly how far it got).
2. **Still to decide** — questions waiting on them, with enough detail to answer later.
3. **Next step** — the exact next thing to do. Not "keep going", but "step 4 in PLAN.md: make the
   Save button store the score".
4. **Watch out for** — anything that's broken right now, or that will catch them out.

Make sure `PLAN.md` is ticked up to date too.

## Then

Tell them it's saved, and that next time they can open the project and type: "read HANDOFF.md and
let's carry on".
