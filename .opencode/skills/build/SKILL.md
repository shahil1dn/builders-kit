# build

## Before writing anything

- **Is there a plan?** If `PLAN.md` exists, do the next unticked step. If there's no plan and the
  job is bigger than a small tweak, suggest `/plan` first.
- **Does this already exist in the project?** Look before you write. Reuse it instead of making a
  second copy.
- **What's the simplest thing that works?** No extra features, settings or tools nobody asked for.

## While building

- Change only what the step needs. Don't tidy up or rewrite other things along the way.
- If you're unsure how a tool or library works, check its docs — don't guess.

## Finish every step the same way

1. **Run it or open it**, and check it does what the step said.
2. **Tell them how to see it** themselves, in one line.
3. **Tick the step** in `PLAN.md`.
4. Say what the next step is, and ask if they want to carry on.

If it doesn't work, say so honestly and use `/debug`. Never say "done" without having checked.

## If they look and something seems off

Take it seriously even if it's vague ("it looks weird"). Ask them to point at what's wrong, or take
a screenshot, before changing anything.
